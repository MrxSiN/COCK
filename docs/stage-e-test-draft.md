All oracles/checkers/workload generation authored for the repository must be BF. Keep the config/event oracles independent in algorithm and data ownership; production output cannot create its expected result. External installed Android/LLVM/signature/JSON/resource tools independently inspect/veto exact outputs; production semantic planning/config/hash/frame/render/sign generation belongs to BF.

Use specifically selected stable API-35 ARM64 device or independently proved bridge; record real build/ABI/page size and usable boot/package/activity services before installing. The previous software emulator failures remain unresolved. A black PNG, advertised bridge or missing package service is not a UI/loader test pass. Capture signed APK/extracted-native/resource/source identities, actual visible screenshots, input coordinates, invocation/PID/generation, state before/after, guest result, renderer acknowledgement and completion evidence. Device input injection must target only task-owned debug apps; no unrelated application data is changed.

For counter, independently expect initial 0, one admitted touch 1, repeated touches count, modulo wrap, no commit on cancellation/redraw failure, and restoration from committed volatile state on window recreation. Process restart resets empty state without persistence. For coordinate app expect READY then ODD/EVEN and schema-2 coordinate bytes; main converter independently swaps two raw bytes with EOF-zero. App sources/assets are currently absent, so these are prospective expectations only.

Failure after visible drawing can preserve old logical state but leaves visual state UNKNOWN; verify safe full redraw rather than assert rollback. A dispatcher status without actual guest return cannot commit. A handler can finish while process stays alive. Every cancellation, physical close, capability error and unsupported irreversible effect must have an actual distinct outcome, not a synthetic guest fuel result.

Report actual DRAFTED/IMPLEMENTED/TESTED/OPTIMIZED/INTEGRATED state per selected capability/E ID, exact tests/identities/exit/limits and every NOT RUN case.
